# Tikka Backend — جاهز

هذا الباك اند مصمم ليعمل مع متجر Tikka الحالي ويقدم:

- تسجيل وإنشاء حسابات + JWT.
- حساب مدير تلقائي عند أول تشغيل.
- إنشاء وحفظ الطلبات.
- ربط الطلب بالعميل.
- حالات الطلب: جديد، مؤكد، قيد التجهيز، جاهز، خرج للتوصيل، تم التسليم، ملغى.
- حالات الدفع: بانتظار الدفع، بانتظار التحقق، تم التحقق، مرفوض، الدفع عند الاستلام.
- دعم Sham Cash ورقم العملية.
- لوحة API للإحصائيات والطلبات والرسائل.
- محادثة خدمة العملاء محفوظة في الخادم.
- PDF للطلب من السيرفر (نسخة لاتينية آمنة؛ ويمكن إضافة خط عربي لاحقاً).
- CORS وRate Limit.
- تخزين محلي بدون قاعدة بيانات مدفوعة.

## التشغيل

### Windows
اضغط مرتين على `start-windows.bat`.

أو:

```bash
npm install
npm run setup
npm start
```

ثم افتح:
`http://localhost:3000/api/health`

## بيانات المدير الافتراضية

من ملف `.env`:
- ADMIN_EMAIL=admin@tikka.local
- ADMIN_PASSWORD=ChangeMe123!

غيّرها قبل أي نشر حقيقي.

## Sham Cash

ضع رقم المحفظة الحقيقي في:
`SHAM_CASH_NUMBER=`

## ربط HTML

الواجهة الحالية ما زالت تستطيع حفظ السلة والطلبات محلياً، لذلك تشغيل هذا السيرفر وحده لا ينقل البيانات إليه تلقائياً. يجب ربط دالة `processOrder()` في HTML مع:
`POST /api/orders`

وتسجيل الدخول مع:
`POST /api/auth/register`
`POST /api/auth/login`

وهذا هو الجزء الذي أستطيع دمجه لك في ملف Tikka نفسه.
